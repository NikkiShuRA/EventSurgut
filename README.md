# EventSurgut - Сайт мероприятий

Пет-проект для изучения и практики вёрстки (HTML/CSS/JS).

## 📋 Описание

Сайт для публикации информации о мероприятиях в Сургуте. Проект включает главную страницу с лентой событий, новостной блок и страницу "О нас".

## 🎯 Цель проекта

- Отработка навыков семантической вёрстки HTML5
- Изучение CSS (Flexbox, Grid, адаптивная вёрстка)
- Практика работы с Git
- Создание доступного и кроссбраузерного сайта

## 📦 Установка и запуск

1. Клонируйте репозиторий:
    ```bash
    git clone https://github.com/NikkiShuRA/EventSurgut.git
    ```

2. Откройте файл `index.html` в браузере или используйте [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) в [VS Code](https://code.visualstudio.com/)
